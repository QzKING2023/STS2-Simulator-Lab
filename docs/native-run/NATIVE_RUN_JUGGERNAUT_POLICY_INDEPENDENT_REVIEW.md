## 3. 旧参考与新路径不能作完整策略因果对照

独立重读确认，旧 `juggernaut-baseline` 与新 DEV_03 的前 575 个确认动作及完整状态/RNG一致，a576 的派发前完整状态也一致。但两者从这里开始采用不同的决策来源：

- 旧参考的前 617 个动作来自冻结路线，之后才切为 v39 live；旧最佳 33 HP 尾部还显式强制了两张防御。
- 新 v40 从正常开局全程在线选择，没有指定前缀或强制动作。
- a576 当时 81 HP、1E、Juggernaut12，Boss 第一形态；旧冻结动作打 Anger，新在线动作打 Defend。旧 v39 源码本身在 Boss 尚无 Nemesis 时把 Anger 评分为负，而 `PreparedCandidates` 在在线模式过滤负分，冻结模式才绕过该排序过滤。因此这个旧 Anger **不是一个可直接当作 v39 在线决策的对照动作**。

所以 119 HP 相对旧 59/33 HP 是不同路线的实际观察结果，不能据此单独量化这条评分规则的整体损害，也不能证明完全回退就会恢复旧表现。

新详细轨迹确实显示 a584 在第二形态打出并耗尽 Impervious，第三形态开始时仅剩 55 HP；旧路线在确认 a595 后进入第三形态时为 67 HP。这些事实提示形态阶段、抽牌顺序和一次性资源使用值得控制，但尚未隔离各自因果。尤其旧 a595 的 Impervious **也已经耗尽**，不能拿这一前缀测试“保留 Impervious”的收益。
