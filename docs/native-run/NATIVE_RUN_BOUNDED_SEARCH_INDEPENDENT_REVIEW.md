## a598 的价值和更集中的替代实验

a598确为可复现的安全入口：turn6、玩家66HP/3E、Boss290HP、Juggernaut12、Strength3。手里有3张零费Strike、Shrug It Off和Inferno。默认序列先打3张Strike，再Shrug抽True Grit。原三动作深度容易把预算花在零费攻击排列上；从此入口继续有研究价值，但尚无证据表明扩大同样的树就能通关。比较多个候选时还应统一到相同的安全回合边界，原“强制动作之后再过两次EndTurn”对含EndTurn的前缀并非相同时域；报告已诚实披露。

建议修复上述两门后，优先以已冻结完整尾部的 **a617确认边界** 做一次小型对照，验证“真实格挡触发输出”这一假设，而非马上重开a598宽树。建议新的独立预算最多8次原生执行：1次精确前缀接口烟测、最多4个事先登记的合法组合、1次完整尾部、1次完整冻结重放、1次预留失败/接口槽；未使用槽位不临时扩大范围。30分钟、2GiB新增证据（含构建/副本）、120秒每进程，先到者停止；保留原96根动作/16回合/128子选择尾部上限。候选不足不补样，错误或状态/RNG不等停止依赖搜索，死亡照实记录。
